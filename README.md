# PKL Modern JS Library

Program perpustakaan sederhana menggunakan Node.js dan JavaScript modern.

## Teknologi

- Node.js
- JavaScript ES Module
- JSON
- File System

## Struktur

data/
- books.json
- authors.json
- loans.json

src/
- repositories/
- services/
- validators/
- utils/
- index.js

## Menjalankan Program

Pastikan Node.js sudah terinstall.

Jalankan:

npm start

atau:

node src/index.js
